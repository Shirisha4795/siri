CSS is used for styling the look and formatting of a document written in HTML

Welcome to Internal CSS Example

Internal CSS applies CSS styles to a specific HTML document. Internal CSS is defined inside an HTML document using style attribute within the head tag of an HTML.

Welcome to Inline CSS Example

Inline style is the approach of adding CSS rules directly to the HTML element using the style attribute.

Welcome to External CSS Example

External CSS is an approach to applying CSS styles to HTML pages by defining the CSS in a separate file.i.e"style.css"
